# Wishwell for Steam

Extensión gratuita para Chrome. Convierte la lista de deseos de Steam en un panel con ofertas de otras tiendas, cuánto dura cada juego y si tira en Steam Deck. Y mucho más.

https://cesferort.github.io/wishwell-site/

La página está en español, euskera e inglés, y ahí está también la privacidad. Todavía no está en la Chrome Web Store.

Wishwell no es un producto de Valve Corporation. Steam y Steam Deck son marcas de Valve Corporation.
